# R8 — UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the entire emerge frontend on top of R1–R7 backends. The plan is opinionated about the *order*: the first three tasks build the §11 cross-cutting foundation (i18n catalog, theme tokens, base components) **before any feature UI is shipped**. Spec §11.4 is explicit — these are day-one mandatory; retrofitting them later destroys quality.

**Architecture:**
- **Vite + React 19 + TypeScript + Zustand + react-router 6**, matching doc-intel-legacy's stack and hot-loaded by Claude Code with high signal-to-noise (per the user's own §11.3 reasoning).
- **Tailwind v3** with `darkMode: 'class'` and a custom palette mapping every utility name to a CSS variable (no direct color classes anywhere). Token names are semantic (`bg-surface`, `text-fg-primary`, `border-default`, `accent-primary`, `status-success`); component code only references these.
- **Radix UI primitives** (Dialog, Select, Switch, Tabs) wrapped in `components/ui/*` shadcn-style. Icons from `lucide-react`. No antd anywhere.
- **`react-i18next`** with one English catalog at `src/i18n/locales/en.json`. Every visible string goes through `useT()` (a thin hook around `useTranslation`). v1 ships English; structure is ready for `zh.json` / `ja.json` to drop in.
- **API client** is one axios instance with a request interceptor that injects the JWT, and a response interceptor that decodes the `{error_code, error_message_en}` envelope into a typed `EmergeError`. UI catches `EmergeError` and renders translated text via the catalog `errors.<error_code>` namespace.
- **Zustand stores** keyed per concern: `useAuth`, `useProjects`, `useDocuments`, `useStudio`. Async actions live inside the store and call the api client directly. No redux, no react-query.
- **Pages** are thin: data fetching in stores, layout in `<Page>` shell, content in feature components. URL is the source of truth (`/projects/:id/studio/:did`).

**Tech Stack:** Vite 8, React 19.2, TypeScript 5.9, Zustand 5, react-router-dom 6.26, Tailwind 3.4, Radix UI primitives, `lucide-react`, `react-pdf` for PDF preview, `react-i18next` 17, `axios` 1.7, `vitest` + `@testing-library/react` for unit tests, `@playwright/test` for E2E (added in this slice).

**Spec sections covered:** §2.1 (NL-first project creation), §2.2 (batch upload + main loop UX), §2.3 (lock prompt), §8.0 (workspace transparent to user), §8.1 (Document list view), §8.2 (Studio 2-column), §8.3 (Schema editor dual mode), §8.4 (intentional non-features), §11.1/11.2/11.3 (i18n, theme, style direction).

**Depends on:** R1 (auth + /me), R2 (projects + documents), R3 (versions + extract), R4 (annotations), R5 (scores), R6 (auto-research), R7 (templates + publish). Some tasks can ship before later backend slices land — see "Dependency notes" at the end.

- [ ] **Step 4: Implement `frontend/src/theme/ThemeProvider.tsx`**

```tsx
import { createContext, useEffect, useMemo, useState, type ReactNode } from "react";

export type Theme = "light" | "dark" | "system";

type Ctx = { theme: Theme; setTheme: (t: Theme) => void };
export const ThemeContext = createContext<Ctx>({ theme: "system", setTheme: () => {} });

function applyResolved(theme: Theme) {
  const resolved =
    theme === "system"
      ? window.matchMedia("(prefers-color-scheme: dark)").matches
        ? "dark"
        : "light"
      : theme;
  document.documentElement.classList.toggle("dark", resolved === "dark");
}

export function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => {
    const saved = localStorage.getItem("emerge.theme") as Theme | null;
    return saved ?? "system";
  });
  useEffect(() => {
    localStorage.setItem("emerge.theme", theme);
    applyResolved(theme);
    if (theme !== "system") return;
    const mq = window.matchMedia("(prefers-color-scheme: dark)");
    const handler = () => applyResolved("system");
    mq.addEventListener("change", handler);
    return () => mq.removeEventListener("change", handler);
  }, [theme]);
  const value = useMemo(() => ({ theme, setTheme }), [theme]);
  return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>;
}
```

import axios, { type AxiosInstance } from "axios";

export class EmergeError extends Error {
  code: string;
  status: number;
  constructor(code: string, message: string, status: number) {
    super(message);
    this.code = code;
    this.status = status;
  }
}

export const api: AxiosInstance = axios.create({ baseURL: "" });

export function setAuthToken(token: string | null) {
  if (token) api.defaults.headers.common.Authorization = `Bearer ${token}`;
  else delete api.defaults.headers.common.Authorization;
}

api.interceptors.response.use(
  (resp) => resp,
  (err) => {
    const data = err?.response?.data;
    if (data && typeof data === "object" && "error_code" in data && "error_message_en" in data) {
      return Promise.reject(
        new EmergeError(
          String(data.error_code),
          String(data.error_message_en),
          err.response.status ?? 500,
        ),
      );
    }
    return Promise.reject(err);
  },
);

```ts
import { create } from "zustand";

import { EmergeError, api, setAuthToken } from "@/lib/api";

type User = { id: number; email: string; workspace_id: number };
type AuthState = {
  token: string | null;
  user: User | null;
  loading: boolean;
  error: string | null;
  init: () => Promise<void>;
  login: (email: string, password: string) => Promise<void>;
  register: (email: string, password: string) => Promise<void>;
  logout: () => void;
};

export const useAuth = create<AuthState>((set) => ({
  token: localStorage.getItem("emerge.token"),
  user: null,
  loading: false,
  error: null,

  async init() {
    const token = localStorage.getItem("emerge.token");
    if (!token) return;
    setAuthToken(token);
    try {
      const me = (await api.get("/api/v1/me")).data;
      set({ user: me, token });
    } catch {
      localStorage.removeItem("emerge.token");
      setAuthToken(null);
      set({ token: null, user: null });
    }
  },

  async login(email, password) {
    set({ loading: true, error: null });
    try {
      const tok = (await api.post("/api/v1/auth/login", { email, password })).data
        .access_token as string;
      localStorage.setItem("emerge.token", tok);
      setAuthToken(tok);
      const me = (await api.get("/api/v1/me")).data;
      set({ token: tok, user: me, loading: false });
    } catch (e) {
      const msg = e instanceof EmergeError ? `errors.${e.code}` : "errors.INTERNAL_ERROR";
      set({ loading: false, error: msg });
    }
  },

  async register(email, password) {
    set({ loading: true, error: null });
    try {
      await api.post("/api/v1/auth/register", { email, password });
      await useAuth.getState().login(email, password);
    } catch (e) {
      const msg = e instanceof EmergeError ? `errors.${e.code}` : "errors.INTERNAL_ERROR";
      set({ loading: false, error: msg });
    }
  },

  logout() {
    localStorage.removeItem("emerge.token");
    setAuthToken(null);
    set({ token: null, user: null });
  },
}));
```

    set((s) => ({ rows: [...created, ...s.rows] }));
  },

import { create } from "zustand";

import { api } from "@/lib/api";

type DocDetail = {
  id: number;
  project_id: number;
  filename: string;
  mime_type: string;
  status: string;
  latest_prediction: { id: number; output: Record<string, unknown>[] } | null;
  latest_annotation: { id: number; output: Record<string, unknown>[]; role: string } | null;
};

type State = {
  doc: DocDetail | null;
  draft: Record<string, unknown>[];
  load: (projectId: number, documentId: number) => Promise<void>;
  setDraft: (next: Record<string, unknown>[]) => void;
  save: (projectId: number) => Promise<void>;
};

export const useStudio = create<State>((set, get) => ({
  doc: null,
  draft: [],
  async load(projectId, documentId) {
    const doc = (
      await api.get(`/api/v1/projects/${projectId}/documents/${documentId}`)
    ).data as DocDetail;
    const seed =
      doc.latest_annotation?.output ??
      doc.latest_prediction?.output ??
      [];
    set({ doc, draft: structuredClone(seed) });
  },
  setDraft(next) { set({ draft: next }); },
  async save(projectId) {
    const cur = get();
    if (!cur.doc) return;
    await api.post(
      `/api/v1/projects/${projectId}/documents/${cur.doc.id}/annotations`,
      {
        output: cur.draft,
        parent_prediction_id: cur.doc.latest_prediction?.id ?? null,
      },
    );
    await cur.load(projectId, cur.doc.id);
  },
}));

## R8 exit criteria

End-to-end browser flow on a fresh DB (with R1–R7 backend running):

1. `npm run dev` boots; `/login` renders in light + dark themes.
2. Register → land on `/projects` (empty list).
3. Click "New project" → see 5 builtins + Empty Project + NL textarea.
4. Pick `custom_blank` → land on `/projects/N` document list, header shows score.
5. Upload 2 PDFs → rows appear with `status=uploaded`.
6. Click "Re-extract remaining" → rows transition to `status=extracted`.
7. Click a row → Studio renders preview placeholder + entity card editor pre-filled from latest prediction.
8. Edit a field → click "Save correction" → success.
9. Open `/projects/N/schema` → form mode shows derived schema; switch to chat tab; submit free text; see proposed candidate in run viewer.
10. After locking via the form mode, "Publish API" unlocks; create API key → reveal modal shows once.
11. Toggle theme → no hardcoded colours flicker.
12. Switch language at runtime (DEV-only by setting `i18n.changeLanguage('zh')` once a `zh.json` is added) — no English strings remain.

Run `cd frontend && npm test` — all component tests pass. `cd frontend && npm run e2e` — walking-skeleton scenario passes.

R8 is the final slice. After R8 the entire emerge v1 platform is shippable; remaining work falls under the v2 backlog (image bbox, named saved views, multi-user real-time, comparison view) and is intentionally out of scope per spec §9.
